# Bhukha Saap

A creative static web project featuring immersive animated landing pages and experimental visual design. The project includes artistic HTML/CSS/JavaScript experiences designed for backgrounds, hero sections, and brand storytelling.

## Overview

This repository contains a small collection of front-end experiments built with plain HTML, CSS, and JavaScript. The visuals focus on:

- animated canvas and SVG motion
- mystical, futuristic, and artistic styling
- lightweight no-build web pages
- simple browser-based viewing with no dependencies

## Project Files

- `jiiis.html` – animated mystical landing page with a glowing green/emerald aesthetic and interactive motion effects.
- `jiss_din.html` – an SVG-based animated dragon/skeleton-inspired design.
- `Untitled design.mp4` – video reference or concept asset.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- SVG and Canvas rendering

## How to Run

Because this is a static front-end project, you can open any of the HTML files directly in a browser.

Option 1:
- Open `jiiis.html` or `jiss_din.html` in your browser.

Option 2 (recommended for local preview):

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## Customization

You can customize the project by editing:

- text content inside the HTML files
- colors and gradients in the `<style>` blocks
- motion behavior and animation logic in the JavaScript sections

## Notes

This project is designed as a visual concept/demo rather than a full production web app. It is intentionally lightweight and easy to modify for branding, portfolio, or concept exploration.
